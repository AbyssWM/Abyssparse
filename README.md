# Abyssparse

**Config parsing library for the Abyss ecosystem.**

Part of [**Abyss**](https://github.com/AbyssWM) · Based on [hyprlang](https://github.com/hyprwm/hyprlang) by [hyprwm](https://github.com/hyprwm)

> [!WARNING]
> **Early development.** Abyss is being rebranded and reworked right now. Nothing is ready for daily use yet.

## About

Abyssparse parses configuration files for Abyss tools that keep a file-based config. Abyssland itself moves to Abysslang (C++ config).

Abyssparse is a fork of [hyprlang](https://github.com/hyprwm/hyprlang). Every Abyss library and tool is forked and renamed, so the whole ecosystem builds and updates as one – independent of system packages.
